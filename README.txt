MY AI STUDIO v0.1

実装済み：プロンプト編集・コピー、SeaArt公式ページへの移動、画像の端末内保存(IndexedDB)、画像ダウンロード、PWAマニフェスト、オフライン用キャッシュ。
未実装：SeaArtへの直接API送信、ログイン連携、AIチャット、AI画像編集、4K/8Kアップスケール。

iPhoneで使用するには、このフォルダをHTTPSの静的ホスティング（GitHub Pages等）に配置し、Safariで公開URLを開き「共有」→「ホーム画面に追加」を選びます。ZIPを開くだけではPWAとしてインストールできません。

SeaArt連携のMCPは公式にはローカルCLIログインとMCPサーバーを前提とするため、iPhone単体PWAからの直接呼び出しはこの版には実装していません。認証トークンをブラウザ側コードに埋め込まないでください。
