# MY AI STUDIO v0.2

GitHub Pages向けの静的PWAです。

## 更新方法（iPhone）

1. ZIPを「ファイル」アプリで展開します。
2. GitHubの `my-ai-studio` リポジトリをSafariで開きます。
3. `Add file` → `Upload files` から、展開したフォルダ**内の5ファイル**（index.html、app.js、sw.js、manifest.webmanifest、icon.svg）をリポジトリのルートへアップロードします。既存ファイルは上書きします。README.mdは任意です。
4. `Commit changes` します。Pagesのデプロイ完了後にサイトを再読み込みします。古い表示ならSafariでページを再読み込みし、必要に応じてホーム画面アイコンを開き直します。

## できること
- プロンプトの入力・コピーと外部サービスへの移動
- AIチャット用の下書きを端末内に保存（**AIの返答はまだありません**）
- 画像の読み込み、iPhone共有シート経由での保存、縮小版ギャラリー（最大8枚）
- ホーム画面への追加、基本的なオフライン表示

## 未実装
- アプリ内AI画像生成、AIチャットの自動応答、画像のAI編集、8K生成
- APIキーや秘密情報をフロントエンドに書き込まないでください。AI連携には安全なサーバー側の中継や認証が必要です。

## 注意
- ギャラリーはlocalStorageに縮小画像を保存します。ブラウザのデータ削除で消えます。元画像は写真アプリ等にも保存してください。
- GitHub Pagesは静的ホスティングであり、単体でAI推論を実行するものではありません。
